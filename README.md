# ✊ Rock-Paper-Scissors Game

An interactive Rock-Paper-Scissors game built using **HTML, CSS, and JavaScript**, featuring score tracking, light/dark mode, and responsive design.

## 🌐 Live Demo

🚀 **[Play the Game on Vercel]([YOUR_VERCEL_DEPLOYMENT_URL](https://rajeshrock-paper-scissor.vercel.app/))**

## ✨ Features
- 🎮 Play against the computer
- 🏆 Automatic score tracking
- 🤝 Draw detection
- 🌙 Light and dark mode toggle
- 📱 Fully responsive design
- 🎨 Interactive UI with hover effects

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Material Symbols

1. Clone the repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the folder in VS Code.
3. Run `index.html` using Live Server.
